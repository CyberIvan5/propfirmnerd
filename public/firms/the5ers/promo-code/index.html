How to use a The5ers code

  1. Open the5ers.com and pick the plan and account size.
  2. At checkout, paste the code into the coupon or promo field and apply it before paying.
  3. Check that the total dropped. If it did not, the code has expired or does not cover that plan.

What a discount does not change

A code lowers the evaluation fee only. It does not change the profit target, the max loss or the payout rules, and at most firms it does not cover activation or reset fees. Most traders who buy an evaluation do not pass it, so the fee is best treated as money you can afford to lose. Read the risks.
